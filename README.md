 PetLovely 🐾

 Sobre o projeto
O PetLovely é um site desenvolvido com o objetivo de apresentar uma loja fictícia especializada em produtos e serviços para animais de estimação, especialmente cães e gatos.

 Funcionalidades

O site possui as seguintes seções:

- Início: apresenta a loja e sua proposta.
- Produtos: apresenta produtos divididos em três categorias: alimentação, brinquedos e higiene. Cada produto possui imagem, descrição e preço.
- Serviços: apresenta os serviços oferecidos pela loja, seus valores e a disponibilidade de tele-busca.
- Contato: disponibiliza informações de contato, endereço e links de navegação.

 Tecnologias utilizadas
- HTML5.

 Navegação
A navegação é realizada por meio dos links disponíveis no menu principal, que direcionam o usuário às diferentes seções da página.
